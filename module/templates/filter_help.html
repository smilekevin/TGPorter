Use single quotes for text, uppercase B/KB/MB/GB/TB for sizes (1KB = 1024B), and YYYY-MM-DD HH:MM:SS for dates. Durations use seconds.

Regular expressions use full matching: r'.*keyword.*' matches text containing keyword. Missing metadata does not satisfy a comparison. Validation checks the expression, not whether a Telegram message matches.

Advertisement keywords are separate: any matching keyword skips forwarding (OR).
